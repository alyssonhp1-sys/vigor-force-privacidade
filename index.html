Política de Privacidade

Vigor Force Gestão

Última atualização: 6 de outubro de 2026

O Vigor Force Gestão é um software de gestão para academias desenvolvido pela Axon Dev. Esta Política de Privacidade explica como as informações cadastradas no sistema são tratadas.

1. Dados tratados pelo sistema

O Vigor Force Gestão permite que a academia registre informações necessárias às suas atividades administrativas, incluindo dados cadastrais de alunos, informações de matrícula, pagamentos e mensalidades, registros de frequência e dados relacionados às avaliações físicas.

2. Finalidade

Os dados são utilizados para permitir o funcionamento das funcionalidades de gestão da academia, incluindo cadastro de alunos, controle de mensalidades, acompanhamento de frequência, avaliações físicas e emissão de relatórios.

3. Armazenamento dos dados

Os dados cadastrados no Vigor Force Gestão são armazenados localmente no computador em que o sistema é utilizado.

O aplicativo não realiza sincronização dos dados dos alunos com servidores da Axon Dev ou serviços de armazenamento em nuvem.

4. Compartilhamento e transmissão

O Vigor Force Gestão não transmite à Axon Dev os dados pessoais cadastrados pela academia.

A Axon Dev não vende nem utiliza esses dados para publicidade, análise de comportamento ou outras finalidades comerciais.

5. Telemetria e análise de uso

O aplicativo não utiliza ferramentas de analytics ou telemetria para enviar à Axon Dev informações sobre os alunos cadastrados ou sobre a utilização do sistema.

6. Responsabilidade pelos dados

A academia que utiliza o Vigor Force Gestão é responsável pelo cadastro, utilização e proteção das informações inseridas no sistema, incluindo o controle de acesso ao computador e ao próprio aplicativo.

7. Segurança

O Vigor Force Gestão utiliza mecanismos de autenticação e armazenamento local destinados a restringir o acesso às funcionalidades administrativas.

A segurança das informações também depende das medidas adotadas pela academia para proteger o computador em que o sistema e seu banco de dados estão armazenados.

8. Correção e exclusão de informações

A gestão das informações cadastradas é realizada pela própria academia por meio das funcionalidades disponíveis no sistema. Solicitações relacionadas aos dados dos alunos devem ser direcionadas à academia responsável pelo respectivo cadastro.

9. Alterações nesta política

Esta Política de Privacidade poderá ser atualizada caso sejam adicionadas novas funcionalidades ou ocorram mudanças na forma como o Vigor Force Gestão trata informações.

10. Contato

Para dúvidas relacionadas ao funcionamento do Vigor Force Gestão ou a esta Política de Privacidade, entre em contato com a Axon Dev por meio dos canais de suporte informados na página do aplicativo.
